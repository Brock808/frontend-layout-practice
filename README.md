# Frontend Layout Practice
 
A collection of layout exercises completed to strengthen my understanding of HTML, CSS and Bootstrap 5 fundamentals.
 
## Overview
 
This repository contains two levels of frontend layout exercises focused on building responsive and well-structured web pages.
 
The project was created to practice modern layout techniques, improve page organization, and develop responsive design skills.
 
## Level 1
 
Topics covered:
 
- Semantic HTML
- Box Model
- Margins and Padding
- Width and Height
- Basic Positioning
- Page Structure
 
## Level 2
 
Topics covered:
 
- Flexbox
- CSS Grid
- Responsive Design
- Media Queries
- Multi-section Layouts
- Navigation Structures
